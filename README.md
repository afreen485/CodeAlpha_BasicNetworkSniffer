# Basic Network Sniffer

## CodeAlpha Cyber Security Internship - Task 1

### Overview

This project is a Basic Network Sniffer developed using Python and Scapy. It captures network packets and displays important information such as MAC addresses, IP addresses, TCP/UDP details, packet payloads, and packet summaries.

### Technologies Used

* Python
* Scapy

### Features

* Captures network packets in real time
* Displays Source and Destination MAC Addresses
* Displays Source and Destination IP Addresses
* Identifies TCP and UDP protocols
* Displays packet payload and summary

### How to Run

```bash
pip install scapy
python sniffer.py
```

### Note

Modern browsers like Chrome and Edge use DNS-over-HTTPS (DoH). Since DNS requests are encrypted and sent through HTTPS (port 443), DNS queries may not appear in the output.
